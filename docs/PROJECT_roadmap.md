# TODO / Roadmap Update（0成本冷启动 → 社区共建 → 融资触发）

本路线图以“精益创业 + 0成本冷启动”为核心：先开源验证需求与体验，再以极低成本验证硬件需求，最后才考虑融资与量产。

---

## Phase 0：纯个人项目（Month 0-6）

### 目标
- 0外部资金，仅个人时间成本
- 完成“感知-上报-确认”闭环（Mac/iPhone）
- 用开源建立信任与技术口碑

### 交付物
- [ ] OpenClaw Eye iOS App（开源 MIT）
- [ ] OpenClaw Hub（macOS 版，开源）
- [ ] 3D 打印支架 STL（开源，带无线充电槽位）

### 商业模式（此阶段不盈利）
- 软件：完全开源
- 硬件：支架图纸开源，用户自行打印
- 收入：无

### 退出条件（方向性指标）
- [ ] 社区关注度显著增长
- [ ] 用户主动询问“是否能买到现成支架”

---

## Phase 1：社区共建（Month 6-12）

### 目标
- 维持 0 融资，尝试小额自造血
- 社区驱动迭代（功能 + 支架）

### 交付物
- [ ] 支架设计迭代（散热/角度/理线/通用接口）
- [ ] 极简 Relay/Cloud（可选，按需付费）
- [ ] 配件成本价销售试验（验证“便利付费意愿”）

### 退出条件（方向性指标）
- [ ] 日活跃用户显著提升
- [ ] 社区明确提出“希望购买成品硬件”

---

## Phase 2：产品化与融资触发（Month 12+）

### 目标
- 只有在需求/技术/供应链都验证后才考虑融资
- 资金仅用于硬件与认证，不用于扩张团队

### 融资触发条件（方向性）
- [ ] 用户明确表达硬件购买需求
- [ ] 软件架构稳定，硬件规格清晰
- [ ] 有供应链报价与成本结构
- [ ] 资金缺口明确、用途清晰

### 融资用途（方向性）
- [ ] 开模 + 首批物料 + 认证

---

## 3D 打印支架的战略定位

### 目的
- 不是硬件产品，而是“体验增强件”
- 降低使用门槛，提高 App 留存与使用率

### MVP 特征（方向性）
- [ ] 15° 倾斜角
- [ ] 无线充电槽位（Qi）
- [ ] 理线槽 + 散热孔
- [ ] 1/4 螺孔（可接三脚架）
